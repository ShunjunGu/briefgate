# DEMO_SCRIPT — BriefGate (1–3 minutes)

**Target length:** ~90–120 seconds  
**Language:** English (rules prefer English; Chinese OK only with English captions/translation)  
**Layout:** Browser window only; hide unrelated tabs/credentials.

## Prep

```bash
cd /path/to/briefgate
npm install
npm start
```

Open http://localhost:3847 — zoom 110–125% if needed.

| Time | Action on screen | Say (approx.) |
